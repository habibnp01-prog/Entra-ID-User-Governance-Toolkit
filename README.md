\# Entra ID User Governance Toolkit



A controlled, interactive PowerShell and Microsoft Graph toolkit for discovering, reviewing, remediating, auditing, and reporting Microsoft Entra ID user governance risks.



The toolkit is designed for administrators who need more than simple GUI-based administration. It provides repeatable governance analysis, controlled remediation, audit logging, and consolidated reporting through PowerShell.



\---



\## Overview



Microsoft Entra ID environments can accumulate inactive, expired, disabled, guest, privileged, and potentially over-provisioned user accounts.



Manually identifying these accounts across different administrative views can be time-consuming and difficult to audit.
